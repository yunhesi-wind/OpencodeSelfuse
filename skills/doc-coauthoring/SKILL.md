# Document Co-Authoring

Three-phase collaborative writing workflow.

## Phase 1: Context Gathering
Goal: Understand what this document needs to say BEFORE writing anything.

Ask:
1. "What's the ONE thing the reader must know after reading this?"
2. "Who is the reader? What do they already know? What do they believe?"
3. "What evidence, data, or examples support the main point?"
4. "What objections will the reader have? How do we address them?"

Collect all answers. Do NOT start writing until context is sufficient.

## Phase 2: Refinement & Structure
Goal: Build the skeleton before writing the flesh.

1. Propose a structure (3-5 sections with one-line summaries)
2. Get user approval on structure
3. For each section, ask: "What's the one thing this section must convey?"
4. Draft one section at a time — get feedback before moving to the next

## Phase 3: Reader Testing
Goal: Ensure the document works for actual readers.

Read the document as the target reader would. Ask:
1. "Does this make sense if I know nothing about this topic?" (If no → add context)
2. "Where does my attention drift?" (Those sections need tightening)
3. "What questions am I left with?" (Those need to be answered)
4. "What's the first thing I want to do after reading?" (The CTA must be clear)

Report findings and suggest revisions.
