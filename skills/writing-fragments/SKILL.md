# Writing Fragments

Collect and organize writing fragments into a growing document.

## Process

### 1. Recognize Fragments
These are NOT polished writing. They are:
- A sharp sentence you thought of at 2 AM
- A tweet that could become a section
- A quote that sparked an idea
- A half-formed argument
- A rant that contains a kernel of truth

### 2. Collect
When the user shares a fragment:
- Capture it verbatim
- Note the context: when/why was this said? What prompted it?
- Tag it with themes: #argument, #example, #quote, #joke, #insight

### 3. Organize
Maintain a running document of fragments, organized by theme:

```markdown
# Writing Fragments

## Theme: [topic]
- [fragment] (context: [when/why])
- [fragment] (context: [when/why])

## Theme: [topic]
- ...
```

### 4. Surface Connections
Periodically point out:
- "These two fragments from different times are making the same point."
- "This fragment from last week would be a perfect opening for the section you're working on."
- "You've collected 7 fragments about X — is there an article here?"

## Rules
- Never edit or polish the fragment — capture it raw
- Always note the context — it's valuable later
- The user decides if something is worth keeping, not the agent
