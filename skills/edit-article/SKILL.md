# Edit Article

Edit and improve articles through structure, clarity, and prose.

## Workflow

### Phase 1: Read-Only Diagnostic
Before making any changes, read the entire article and answer:
1. What is the ONE main argument?
2. Does the structure serve that argument? (Is there a logical flow?)
3. Where does the prose drag? (Mark specific sentences)
4. What is missing?

### Phase 2: Structure
- Ensure introduction states the thesis within first 2 paragraphs
- Each section should make exactly one point
- Transitions between sections should be logical, not mechanical
- Check: if you remove a section, does the article still work? If yes, it's redundant.

### Phase 3: Clarity
- Replace jargon with plain language unless the audience demands it
- Short sentences > long sentences (aim for 15-25 words max in English)
- Active voice > passive voice
- Concrete examples > abstract claims

### Phase 4: Prose Tightening
- Delete:
  - Filler phrases: "it is worth noting that", "needless to say", "in order to"
  - Redundant pairs: "each and every", "first and foremost"
  - Weak qualifiers: "very", "quite", "rather", "somewhat"
- Replace:
  - Nominalizations: "make a decision" → "decide"
  - Weak verbs: "is indicative of" → "indicates"
- Keep:
  - The author's unique voice and style
  - Discipline-specific terminology where appropriate

### Phase 5: Final Check
- Show changes as a summary: what was restructured, what was tightened
- Ask user to review before finalizing
