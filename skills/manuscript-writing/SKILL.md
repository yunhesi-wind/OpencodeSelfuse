# Manuscript Writing

Structure and draft research manuscripts using IMRaD format.

## IMRaD Structure

### Introduction (Why?)
- What is known? (Background, ~30%)
- What is unknown? (Gap, ~20%)
- What did we do? (Approach, ~20%)
- What did we find? (Summary, ~10%)
- What does it mean? (Implication, ~10%)
- End with: Hypothesis or research question explicitly stated

### Methods (How?)
- Experimental design
- Participants/samples
- Data collection procedures
- Statistical analysis
- Software and versions
- Ethical approval statements
- Write in past tense, passive voice OK

### Results (What?)
- Present findings without interpretation
- Reference figures/tables: "(Figure 1A)", "(Table 2)"
- Use subheadings to group related results
- Report statistics: test, statistic value, df, p-value, effect size
- "Significant" only when p < 0.05

### and Discussion (So What?)
- Restate main finding (1 sentence, past tense)
- Compare with prior work: "Consistent with..." / "In contrast to..."
- Explain unexpected results
- Limitations (honest, not defensive)
- Implications and future directions

## Abstract Structure
1. Background (1 sentence)
2. Objective (1 sentence)
3. Methods (1-2 sentences)
4. Results (2-3 sentences with key numbers)
5. Conclusion (1 sentence)

## Title Checklist
- [ ] Contains key variables
- [ ] States the relationship (if known)
- [ ] No abbreviations
- [ ] No "Study of...", "Investigation of..."
- [ ] Under 20 words
- [ ] Specific, not vague
