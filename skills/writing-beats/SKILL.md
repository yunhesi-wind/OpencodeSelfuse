# Writing Beats

Shape articles as a journey through beats. Each beat is a story moment.
The reader chooses their path through the material.

## Process

### Step 1: Map the Beats
From the raw material, extract distinct "beats" — moments, insights, or turns in the narrative.
```
Beat 1: The hook (why should I care?)
Beat 2: The problem (what's broken?)
Beat 3: The insight (the "aha" moment)
Beat 4: The evidence (proof it works)
Beat 5: The implication (so what?)
Beat 6: The call (what now?)
```

### Step 2: Offer Paths
Present the user with narrative choices:
"Your article has these beats. Which path feels right?"
- **Problem-first**: Start with pain, then reveal solution
- **Insight-first**: Lead with the surprising finding, then explain how you got there
- **Journey**: Chronological narrative of discovery
- **Debate**: Present both sides, then resolve

### Step 3: Draft Per Beat
Draft each beat. After each beat, ask:
"This works. Next beat is [X]. Want to proceed or reshape?"
