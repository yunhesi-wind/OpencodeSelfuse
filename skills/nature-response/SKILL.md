# Nature Response

Draft or audit point-by-point reviewer response letters.

## Response Letter Structure

```
Dear Editor,

[1-2 sentences thanking editor and reviewers, summarizing key changes]

Below, we respond to each comment point by point. Reviewer comments are in italics;
our responses follow. Changes to the manuscript are highlighted.

Sincerely,
[Authors]
```

## Response Format (per comment)

```markdown
**Reviewer 1, Comment 1:** [Restate the comment verbatim]

**Response:** [Your response]

**Action:** [What was changed in the manuscript, with page/line numbers]
```

## Response Principles

### 1. Be Respectful
- Every comment is valid, even if you disagree
- "We thank the reviewer for this insightful observation"
- Never argue, never dismiss — explain

### 2. Be Complete
- Address EVERY comment individually
- For multi-part comments, address each part separately
- If you disagree, explain WHY with evidence — don't just say "we disagree"

### 3. Be Specific
- Quote the EXACT text that was changed
- Provide line numbers where changes were made
- When adding new data/analysis, summarize what was found

### 4. Audit Checklist
When reviewing a draft response:
- [ ] Every reviewer comment has a response?
- [ ] No dismissive or argumentative language?
- [ ] All claimed changes actually exist in the manuscript?
- [ ] Line numbers are correct?
- [ ] New data/figures are referenced correctly?
- [ ] The response letter itself is well-organized?

## Rules
- If a reviewer request is impossible, explain WHY — don't just say it can't be done
- If a reviewer misunderstood something, clarify — don't blame them for not understanding
- The editor reads the response first — make it easy for them to see what changed
